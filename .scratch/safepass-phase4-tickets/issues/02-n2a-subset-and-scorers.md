## 目标 / 缺口 / 做法 / DoD / 加分

- **目标**：钉死对照用的 20 条金标，并交出可独立验收的三项确定性打分。
- **缺口**：N2 还没有钉死 ID 与可测口径；执行计划原文「幻觉率」不能直接套 L2 judge。
- **做法**：夹具钉死 ID；纯函数实现无证据事实声明 / 越界编造 / 评级一致性；用合成文本测红绿，零 LLM。
- **DoD**：20 个 ID 均在金标中且改名单即红；合成用例覆盖空证据、有片段支撑、越界编灯、未评级；不调用模型。
- **加分**：对照的尺子先于生成器存在，避免边录边改口径。
- **Craft**：T2（本票只交尺子，三列对照在 N2b）。

## 波 2 第一刀定案（P8，效力优先）

1. ID 覆盖内：G25 G27 G31 G34 G35 G36 G37 G40 G41 G42 G44 G45 G47；越界：G01 G02 G05 G07 G08 G09 G10。不含追问/紧急/G49–G50/画像敏感条。
2. 不称 L2 幻觉率。裸 LLM 证据为空；无约束 RAG 以所塞知识片段为证据。
3. 本票不实现裸 LLM / 无约束 RAG 生成器，不写三列对照文档终表。
