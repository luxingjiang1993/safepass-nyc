# 法拉盛（109警区）日常防范与华人常见诈骗提醒

## 针对华人的高频诈骗类型

### 1. 冒充使领馆 / 冒充公检法电话诈骗

- 作案手法：自称中国使领馆、国内公安/检察院，声称当事人涉案、证件异常，要求转账"保证金"或视频笔录配合"秘密调查"。
- FBI IC3 与 FTC 均有面向公众的英文防骗公告（见来源）；此类诈骗在华埠与法拉盛华人社区反复出现（经验性描述）。
- 防范要点（经验性建议）：使领馆不会电话要求转账；遇到"保密要求"即高度可疑，挂断后自行拨打官方公开电话核实。

### 2. 换汇诈骗 / 私下换汇纠纷

- 法拉盛私下换汇需求大，微信/论坛换汇常见"先款后逃"、假转账截图、换汇现场抢劫等手法。
- 本知识库未收录 109 警区换汇诈骗逐案统计：**逐案统计：未记载**。以上为经验性提醒。

### 3. 街头与商业区扒窃

- 缅街商业区拥挤，注意背包前背；餐馆/超市排队付款时手机与钱包不要随手放置。
- 经验性建议，非逐案统计。

### 4. 快递/银行钓鱼短信

- 冒充 USPS/银行发送"包裹异常""账户冻结"链接，窃取银行卡信息。
- 防范要点（经验性建议）：不点陌生链接，通过官方 App 核实。
