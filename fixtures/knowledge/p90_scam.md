# 威廉斯堡（90警区）日常防范与华人常见诈骗提醒

## 针对华人的高频诈骗类型

### 1. 冒充使领馆 / 冒充公检法电话诈骗

- 作案手法：自称中国使领馆、国内公安/检察院，声称当事人涉案、证件异常，要求转账"保证金"或提供银行账户信息。
- FBI IC3 与 FTC 均有面向公众的英文防骗公告（见来源），此类诈骗在华人社区反复出现。
- 防范要点（经验性建议）：使领馆不会电话要求转账；涉及"秘密配合调查"的说法可直接挂断并拨打 911 或向警局核实。

### 2. 租房 / 押金诈骗

- 威廉斯堡租户流动性大：常见假房源收押金、二房东卷款、假房东钥匙骗局（经验性描述）。
- 防范要点（经验性建议）：签约前核实房东/管理公司身份，押金走正规渠道并留凭证。

### 3. 换汇与二手交易诈骗

- 私下换汇"先款后逃"、二手交易（家具/电动车）收款不发货在租房社区常见（经验性描述）。
- 本知识库未收录 90 警区上述诈骗逐案统计：**逐案统计：未记载**。

### 4. 快递/银行钓鱼短信

- 冒充 USPS/银行发送"包裹异常""账户冻结"链接，窃取银行卡信息。
- 防范要点（经验性建议）：不点陌生链接，通过官方 App 核实。
