# 用户画像不改变安全评级，只影响建议层

用户画像（性别、身份、场景标签等）的作用域限定为：时间风险提示的个性化表述、贴心建议的生成语境与排序。安全评级永远只由数据相对阈值计算（ADR-0001），画像不参与、不改变评级。

**为什么**：同一条街道对不同用户显示不同颜色会让用户怀疑数据造假，违背"评级可解释、可回溯"原则；数值化的"风险系数"（如女性夜间 ×1.2）是伪精确，系数没有可辩护的调参依据。PRD v1.1 中 F4-2/AC-012 的"风险系数"表述由此废弃，改写为建议层与时间提示的个性化。

> **修正（2026-09-07，ADR-0003，只追加不改原文）**：首段"贴心建议的**生成语境**与排序"中的"生成语境"已收窄废弃——画像永不离开服务进程、不进入任何 LLM 请求体（SuggestionPack 结构上无画像字段），作用域仅为**本机确定性**的建议排序/加权与时间风险提示个性化表述。评级结论不受本修正影响。
