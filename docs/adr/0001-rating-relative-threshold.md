# 安全评级采用相对阈值 + 样本量门控

安全评级（🔴🟡🟢⚪）不采用绝对犯罪率数字，也不交给 LLM 定性判断，而是：该警区过去 12 个月 per-100k 犯罪率与 NYC 全市均值比较（<0.7× → 🟢，0.7–1.3× → 🟡，>1.3× → 🔴），样本量低于显著性阈值时强制 ⚪ 数据不足、不给出评级。系数 0.7/1.3 是写入 PRD 的可调参数，不允许散落在代码中。

**为什么**：MVP 数据集是自造的模拟数据，绝对阈值没有外部锚点，面试时无法解释数字来源；LLM 定性判断违背"评级可解释、可回溯"的产品原则，且无法保证"不夸大风险"的负面验收。相对阈值让评级随数据全集自动校准，与 sample_size/显著性体系闭环。
