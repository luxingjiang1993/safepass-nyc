## Problem Statement

波 1 已经让用户看见受约束的 AI 建议、首屏能决策、话术改不了灯、一键能复现。作品集轴上还空着验收看板 **#17**：审阅者无法把 SafePass 和「裸 LLM / 把检索结果直接塞进提示」放在同一张表上对比，无法回答「你和会调 API 的人差在哪」。同时结果页虽有建议依据槽位，空态不假装有出处，但 **有依据时缺少「建议依据」标题、无依据时缺少「通用建议」标注**，用户（尤其习惯 Perplexity 的人）感觉不到 RAG。

用户还希望将来能多轮问答（问不准、要追问）。那是后 100 分的三模式路由，**不是本刀问题**；本刀只补「可打假的对照」和「依据可见」。

## Solution

两张可并行、互不依赖的票，共一个出口：波 2 第一刀收口。

- **N2 基线对照**：钉死的 20 条金标上，三列 **裸 LLM / 无约束 RAG / SafePass**。无约束 RAG 与主路径共用混合检索 top-3 知识片段，不做依据校验、不禁止模型写灯、不塞图表或全市倍数、不故意劣化检索。指标全是确定性规则：无证据事实声明率、越界编造率、评级一致性（SafePass 必须 100%）。数字和 3 个失败样例落一页对照文档。复跑走 eval 套件 + 生成 cassette，**不进**默认行为基线。
- **A4 建议依据**：覆盖内结果页建议区，列表级渲染已有建议依据；非空时小号标题「建议依据」；空时标明「通用建议」。不改建议依据的数据结构，不把一条建议绑一条依据，不把 Top 罪名/昼夜比抄到每条建议下（那些是图表和核心结论行的职责）。越界页已有的「通用建议」语义保持「无本区数据」，不借本票改口径。

后 100 分（精准查询 / Plan / ReAct 兼得）只登记在执行计划 P7/§11，本 spec 不实现。

## User Stories

1. As a 面试官视角的审阅者，I want 同一批查询上看到裸 LLM、无约束 RAG、SafePass 三列数字，so that 我能判断约束是否比「会检索」更值钱。
2. As a 面试官，I want SafePass 的评级一致性为 100%，so that 我相信灯不是模型拍的。
3. As a 面试官，I want SafePass 的越界编造率为 0，且另两列在越界子集上至少各有一例编造，so that 对照真正拉开，而不是三列一起装老实。
4. As a 面试官，I want 无证据事实声明率 SafePass 严格低于另两列，so that 「显著优于」是布尔条件而不是 p 值散文。
5. As a 面试官，I want 对照页上有 3 个失败样例（对照列翻车、SafePass 做对），so that 我不用自己猜数字背后的故事。
6. As a 开发者，I want 20 条查询 ID 钉在夹具里且改名单即红，so that 换人重跑不会漂成另一场考试。
7. As a 开发者，I want 默认 `python -m pytest tests/ -q` 仍然不跑这场对照，so that 裸模型请求指纹不污染 663 基线。
8. As a 开发者，I want 对照列的检索与产品同一套混合检索 top-3，so that 我不是把对手绑起来比赛。
9. As a 开发者，I want 对照列的提示里没有图表和相对全市倍数，so that 无约束 RAG 不是「漏了校验器的 SafePass」。
10. As a 开发者，I want 无证据事实声明不叫 L2 幻觉率，so that 改 judge 提示词不会误伤这张对照表。
11. As a 越界查询的用户，I want 对照实验仍用「哥大附近」这类金标，so that 编造灯色会被抓住。
12. As a 覆盖内用户，I want 五区都有代表查询，并包含数据不足的布鲁克林高地，so that 对照不是只考绿灯区。
13. As a 开发者，I want 不含追问、紧急、一句话对比、画像敏感条，so that 三列都只吃当句查询、画像口径一致。
14. As a 开发者，I want SafePass 列仍走唯一接缝，so that 对照测的是产品而不是平行实现。
15. As a 开发者，I want 裸 LLM 与无约束 RAG 只存在于评测/脚本，so that 生产路径不会突然变成陪聊。
16. As a 开发者，I want 生成 cassette 与 L2 judge cassette 分文件，so that 重录对照不会踩 L2 棘轮。
17. As a 开发者，I want 测试世界钉在 mock 数据集上，so that 金标期望和检索原文与波 1 同一世界。
18. As a 用户，I want 有建议依据时看见「建议依据」和原文片段，so that 我知道建议不是凭空写的。
19. As a 用户，I want 无建议依据时看见「通用建议」，so that 模板降级不会装成有出处。
20. As a 用户，I want 没有依据时不要出现假引用行，so that 空态保持诚实。
21. As a 用户，I want 建议依据是整段建议下面的一块，so that 我不必猜测第几条对应哪句引文（契约本就不是逐条对齐）。
22. As a 用户，I want 首屏「评级依据」（全市倍数）和「建议依据」用词分开，so that 两套出处不打架。
23. As a 越界用户，I want 越界页原来的「通用建议」折叠含义不变，so that A4 不把「无本区数据」改成另一种空依据。
24. As a 开发者，I want 建议依据的槽位类名不漂，so that D1 结构锁和日后引用高亮仍认同一槽。
25. As a 开发者，I want 抽检有依据与无依据在 HTML 上可分，so that A4 的 DoD 能自动测。
26. As a 开发者，I want 依据文本能在检索片段或夹具文档里找到，so that 页面不是装饰性引用。
27. As a 隐私视角的用户，I want 本刀不把画像送进任何新的模型请求，so that 零上传口径不破。
28. As a 紧急场景用户，I want 本刀不改紧急页，so that 极简电话路径不被依据区打乱。
29. As a 项目作者，I want N2 与 A4 可以两个窗口一起做，so that 无 key 时依据可见仍能先绿。
30. As a 项目作者，I want 后 100 分的 Plan/ReAct 不出现在本刀完成承诺里，so that agent 不会顺手做聊天。

## Implementation Decisions

- **范围**：只交付 N2 与 A4。执行计划第 4 波、D5 覆盖文案、C5 澄清、A5 画像可感知、三模式路由全部不在本刀。
- **并行**：N2 与 A4 无合并前置。无模型密钥时 A4 仍可收口；N2 录制生成 cassette 需要开发模型密钥与日预算。
- **N2 查询集**：二十个金标 ID 钉死为覆盖内 `G25 G27 G31 G34 G35 G36 G37 G40 G41 G42 G44 G45 G47` 与越界 `G01 G02 G05 G07 G08 G09 G10`。改名单必须让钉死夹具的测试变红。
- **N2 三列**：
  - 裸 LLM：只有用户查询文本，无检索、无统计表。
  - 无约束 RAG：同一混合检索 top-3 知识片段整段进入提示；无依据逐字校验；不禁止输出灯色或犯罪数字；不注入图表或相对全市倍数；不换更差的检索器。
  - SafePass：唯一接缝执行查询（测试世界钉 mock 数据集），与产品主路径同构。
- **N2 指标（确定性，禁止复用 L2 幻觉 judge）**：
  - **无证据事实声明**：出现犯罪数字、四级安全评级或具体案件量，却没有对应证据（裸 LLM 证据为空；无约束 RAG 以所塞片段为证据；SafePass 相对图表/检索摘要及越界不得编数据）。
  - **越界编造**：越界子集上仍给出该地点的安全评级或犯罪率数字；SafePass 必须为 0；另两列在该子集上至少各 1 例，否则票未完成。
  - **评级一致性**：若输出了灯色/四级结论，则与评级引擎（或金标期望评级）对账；未输出记「未评级」。SafePass 必须 100%。
- **N2 工件**：对照文档须含三列表、上述布尔收口、3 个失败样例。对照列实现不得进入主应用依赖、不得把 LangChain 引进主路径。
- **N2 接缝**：SafePass 列只打唯一接缝。对照列是评测专用生成器，不是新的产品接缝。打分是纯函数，不调用 judge。
- **A4 契约**：建议依据仍是整份安全查询结果上的列表，不增加「第 i 条建议对应第 i 条依据」。
- **A4 渲染**：覆盖内建议区有依据 → 保留现有槽与类名，加小号「建议依据」并列出引文（可带文档名，无点击打开全文）。无依据 → 建议区标明「通用建议」，不渲染假引用。不把 Top 罪名或昼夜比重复绑到每条建议下。
- **A4 越界页**：已有「通用建议」表示无本区数据，本票不改该语义。
- **A4 接缝**：结果页 HTML（给定契约的纯渲染）。不改评级引擎、不改 Skill 打包、不改建议依据 schema。
- **红线**：LLM 不写评级/可信度/越界判定；画像不进新的供应商请求；运行时不直连外部数据 API。

## Testing Decisions

- 好测试只锁外部行为：对照表数字与布尔收口、HTML 上有依据/无依据可分、钉死 ID 与金标存在性。不锁对照列提示词全文、不锁 CSS 像素。
- N2 放在 eval 套件一侧（与 L2 一样被默认基线排除）。回放零网络；录制脚本与回放共用同一 mock 数据世界钉子。生成 cassette 与 L2 judge cassette 分开。故意改 20 个 ID 的夹具 → 红。
- 「显著优于」写成断言：SafePass 越界编造率 = 0；无证据事实声明率严格低于另两列；另两列越界子集编造次数 ≥ 1；SafePass 评级一致性 = 100%。
- A4 优先扩现有首屏/渲染测试：有依据时出现「建议依据」与引文；无依据时出现「通用建议」且无装成有出处的引用块；槽位类名仍在；越界页旧语义回归不断。依据文本相对夹具/检索原文可核对。
- 唯一判定命令不变：`python -m pytest tests/ -q` 全绿（基数随 A4 递增）。N2 另跑 eval 目录下本票测试。禁止裸跑 `pytest`。
- 先验：注入报表脚本与 L2 runner 的「夹具 + 离线回放 + mock 世界钉」；D1 首屏结构锁（内容可变、槽位不漂）。

## Out of Scope

- 第 3–4 波全部（含引用高亮点击打开原文、失败分类学、知识库加厚、a11y、动效）。
- 后 100 分：Plan / ReAct / 精准查询三模式路由、对话条、IM、把结果页喂给模型再陪聊。
- D5 覆盖诚实文案、C5 地址歧义澄清轮、A5 画像差异演示。
- 重做 N1 骨架或 N3 一键复现。
- 把 N2 塞进默认行为基线；用 L2 幻觉 judge 给对照列打分。
- 无约束 RAG 注入统计表或故意劣化检索。
- 改建议依据 schema、逐条对齐、LangChain/LlamaIndex/服务型数据库。
- 扩核心警区、路径级安全、LLM 参与评级。
