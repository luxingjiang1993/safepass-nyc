## Problem Statement

波 2 第一刀已经让审阅者看见三列对照，结果页也能区分「建议依据」与「通用建议」。打开覆盖内结果页时，人话解释仍停在 D1 占位：一句全市倍数散文，和核心结论行里的倍数钩子重复，也说不清样本档、更说不清为何亮 ⚪。Walk Score 式「分旁边那句固定人话」还没成为契约字段。

审阅者仍无法 pytest 卡住「query 该命中哪篇知识文档」；改索引不一定红。脏输入（超长、空、中英混、复读）没有专表，T2 会问线上全是垃圾输入怎么办。首页 Hero 仍是「安全管家」问候，没有「数据评级，AI 只建议」；覆盖范围没有主动说清「只这五区、越界会怎样」——那是覆盖诚实，不是扩警区。

画像差异可感知（A5）和把六维画像送进模型是另一场 ADR 讨论，不是本刀要解决的用户问题。

## Solution

五张票、两个槽，共一个出口：波 2 第二刀收口（看板本刀相关项：C1 溯源人话、B4 检索回归、N4 脏输入、D5 首页价值主张、C6 覆盖边界；L2 因契约增字段而重录）。

- **槽 1（可并行）**
  - **C1a**：覆盖内安全查询结果增加确定性字段「评级依据」人话（契约名 `rating_rationale`）。配置里按绿 / 黄 / 红 / ⚪ 四套模板，纯函数填相对全市倍数、样本档、为何 ⚪。结果页用该字段 **替换** 现有硬编码倍数行，与核心结论行不并存第二句同义倍数。越界页与紧急页不写该字段。
  - **B4**：约 20 条「查询 → 应命中文档标识」标注（优先复用已有金标与知识锚点），断言混合检索 top-3 命中；BM25-only 与混合检索对照表写一次进文档。测试世界钉 mock。
  - **N4**：对唯一接缝做 pytest 参数化脏输入。非法只能落到紧急 / 防线拒绝 / 诚实降级之一；禁止半残的覆盖内安全契约；安全路径上安全评级仍只由确定性引擎写出。不加新的属性测试框架依赖。
- **槽 2（C1a 合并之后）**
  - **C1b**：因完整安全查询结果进入 L2 judge 请求，新增字段会改指纹。重录 L2 生成 cassette，评测套件回放全绿。不进默认行为基线。
  - **D5 并 C6**（用户点名）：首页 Hero 改为「中文安全情报；数据评级，AI 只建议」+ 查询框 + 五区入口（区名来自配置，禁止代码写死警区号）。主动写清只覆盖五个核心警区、越界诚实降级。结果页标明本次命中警区与覆盖清单同源；越界页对比「若在覆盖内你会看到什么结构」（槽位结构，不编造该地点的灯）。

后 100 分精准查询 / Plan / ReAct 不实现。A5 画像进模型不实现，须另开 ADR grilling。

## User Stories

1. As a 覆盖内用户，I want 首屏在核心结论行之下看到一行「评级依据」人话，so that 我知道这盏灯相对全市和样本意味着什么。
2. As a 覆盖内用户，I want 绿灯时人话同时提到相对全市倍数和样本档，so that 我不会把「相对安全」理解成零风险。
3. As a 覆盖内用户，I want 黄灯 / 红灯时人话说明倍数落在哪一档，so that 灯色和倍数不打架。
4. As a 覆盖内用户，I want ⚪ 时人话说明样本量未过显著性门槛因此不评级、不给倍数，so that 我不会把「数据不足」当成安全。
5. As a 覆盖内用户，I want 不再同时看到旧的「约为全市均值 X.X 倍」硬编码句和新的评级依据句，so that 首屏没有同义反复。
6. As a 覆盖内用户，I want 核心结论行仍然短、仍含允许的数据钩子，so that 5 秒决策那一行不被评级依据挤掉。
7. As a 覆盖内用户，I want 「评级依据」和「建议依据」用词分开，so that 全市倍数解释不会被当成检索引文。
8. As a 越界用户，I want 越界页不出现覆盖内那套评级依据人话，so that 「无本区数据」不会被说成 ⚪。
9. As a 紧急场景用户，I want 紧急页不加评级依据槽，so that 极简电话路径不被审计句打乱。
10. As a 开发者，I want `rating_rationale` 只出现在覆盖内安全查询结果契约上，so that 对比 / 紧急 / 防线 / 降级形态不会被硬塞灯色解释。
11. As a 开发者，I want 四套人话模板活在配置里，so that 阈值与档位字面量不进 Python。
12. As a 开发者，I want 倍数与核心结论行全市倍数钩子同一位小数口径，so that 同屏不出现 0.7 与 0.67 打架。
13. As a 开发者，I want 评级依据由纯函数在装配安全查询结果时写出，so that LLM 零参与安全评级解释（ADR-0001）。
14. As a 开发者，I want 绿 / 黄 / 红 / ⚪ 各有快照或结构断言，so that C1 DoD 可机器收口。
15. As a 开发者，I want 公式展开表不进本刀，so that C1 不和敏感性扫表抢范围。
16. As a 面试官视角的审阅者，I want 一组 query → 应命中文档标识 的回归，so that 混合检索不是简历关键词。
17. As a 开发者，I want 约 20 条标注且优先复用已有金标与知识锚点，so that 不新写 40 条知识、也不只靠对照子集 13 条覆盖内 ID。
18. As a 开发者，I want 断言混合检索 top-3 包含应命中文档，so that 召回失败会红。
19. As a 开发者，I want 故意改坏索引或标注能让该回归变红，so that 检索质量有门闩。
20. As a 开发者，I want BM25-only 与混合检索对照表写进仓库文档一次，so that 面试能指着表讲 RRF 为什么在。
21. As a 开发者，I want 检索回归钉在 mock 数据世界，so that 与金标、L2、N2 同一世界。
22. As a 开发者，I want community_info 仍不参与检索排序，so that 不踩既有棘轮。
23. As a 面试官，I want 看到超长、空、中英混、复读等脏输入仍有合法形态，so that 我相信线上垃圾输入不会半残出页。
24. As a 开发者，I want 脏输入要么紧急、要么防线拒绝、要么诚实降级，so that 不会出现缺字段的覆盖内安全契约。
25. As a 开发者，I want 脏输入若仍走进覆盖内安全路径，安全评级比特仍只来自引擎，so that 话术和乱码都改不了灯。
26. As a 开发者，I want 脏输入测试用参数化而不是新框架，so that 不引入 hypothesis 依赖。
27. As a 开发者，I want 评测夹具里允许用表情符号当输入样本，so that 能覆盖那一类脏输入；产品文案仍不写表情符号。
28. As a 开发者，I want N4 不替代 N1，so that 语义攻击与畸形输入分表。
29. As a 用户，I want 首页三秒内读到「中文安全情报；数据评级，AI 只建议」，so that 我知道灯不是 AI 拍的、建议才是 AI。
30. As a 用户，I want 首页仍有查询框和五个核心警区入口，so that 我不用会写高级查询。
31. As a 用户，I want 五区名称来自配置别名而不是写死的警区号，so that 改覆盖清单只有一个事实源。
32. As a 用户，I want 首页写清只覆盖这五个核心警区，so that 我不会以为全市都能亮灯。
33. As a 用户，I want 首页写清查到核心警区外会诚实降级、不编灯，so that 覆盖诚实在进查询前就看见。
34. As a 覆盖内用户，I want 结果页能看见「我们覆盖这些区；你这次命中的是 X 警区」，so that 范围叙事主动。
35. As a 越界用户，I want 越界页展示若在覆盖内会看到的槽位结构（评级 / 结论行 / 建议等），so that 我理解降级少了什么、而不是被塞一个假灯。
36. As a 越界用户，I want 那份结构示意不出现该地点的安全评级或犯罪率，so that C6 不破坏诚实降级。
37. As a 开发者，I want 覆盖清单与核心警区配置同源，so that 首页、结果页、越界页不会各写一份五区。
38. As a 开发者，I want D5/C6 等 C1a 合并后再改结果页渲染，so that 不与评级依据替换抢同一结果页。
39. As a 开发者，I want C1a 合并后立刻重录 L2 cassette，so that judge 请求里的新字段不会让回放指纹全灭。
40. As a 开发者，I want 默认行为基线仍然不跑 L2，so that C1a 可以在无 key 时先绿。
41. As a 开发者，I want C1b 收口条件包含评测套件回放全绿，so that 「接受重录 L2」是布尔而不是口头。
42. As a 隐私视角的用户，I want 本刀不把画像送进任何模型请求，so that 零上传口径与 ADR-0003 不动。
43. As a 项目作者，I want A5 留在 ADR 讨论之后，so that 不会在未改架构时把六维画像塞进 Skill。
44. As a 项目作者，I want 本刀不做 Plan/ReAct/对话助手，so that 后 100 分门闩不被偷渡。
45. As a 项目作者，I want 不重做 N1 骨架、N3 一键复现、N2 三列、A4 依据槽，so that 已关票不被再实现一遍。

## Implementation Decisions

- **测试接缝（优先已有、尽量少）**
  1. 产品唯一接缝仍是 `execute_query`：C1a 的人话必须出现在该接缝返回的覆盖内安全查询结果上；N4 只打该接缝。
  2. C1a 展示接缝：结果页渲染读取 `rating_rationale`，替换旧倍数散文；不新开 HTTP 路由。
  3. B4 接缝：直接打混合检索 `search`（返回按融合分排序的文档标识），不断言 HTML、不经建议 Skill。需要 BM25-only 对照时，用与产品同一索引上的关键词检索排序，禁止另起一套语料。
  4. C1b 接缝：既有 L2 评测运行器（把完整安全查询结果序列化进 judge 请求）。只重录、不改 judge 口径，除非指纹证明必须改提示词（本刀默认不改）。
  5. D5/C6 接缝：首页渲染、覆盖内结果页渲染、越界降级页渲染；警区清单只读覆盖配置。
- **C1a 契约**：覆盖内 `SafetyQueryResult` 增加必填字符串 `rating_rationale`（可与空字符串策略相反：四档都必须非空人话）。不进入 Skill 输出契约，不进入建议依据列表。对比 / 紧急 / 防线 / 越界降级契约不加该字段。
- **C1a 装配**：在确定性评级完成之后、安全查询结果出唯一接缝之前，纯函数按灯色选配置模板并填钩子（倍数、样本量、样本档中文）。LLM 不得写该字段。阈值 0.7 / 1.3 与样本量门槛只从配置读。
- **C1a 模板**：配置内四套（绿 / 黄 / 红 / ⚪）。⚪ 模板不得含倍数占位。样本档对外中文（数据量有限 / 适中 / 充足），不把 HIGH 等枚举名直接给用户。
- **C1a 首屏**：核心结论行保留；其下仅一行「评级依据：」+ `rating_rationale`。删除 D1 硬编码「该警区犯罪率（per 100k）约为全市均值的 X.X 倍」。页头可信度 / 样本量说明可保留，不在本刀删除。
- **C1a 并行文件**：槽 1 独占安全查询契约、装配该字段的管线、评级相关配置模板、结果页「评级依据」替换。B4 / N4 不得改这些表面。
- **C1b**：槽 2。重录 L2 相关 cassette 与评测工件；禁止改 N2 三列 cassette；禁止把 L2 拉进默认 `tests/` 收集。
- **B4 标注规模**：约 20 条，覆盖五核心警区与诈骗 / 夜间等主题差异；应命中文档标识必须存在于当前知识 / 索引元数据。nDCG 小组不是本刀硬门闩；Recall@k 以 top-3 命中布尔为主。
- **N4 输入类**：空 / 仅空白、超长、中英混杂、复读机、控制字符；评测输入可含表情符号。不把产品 UI 文案改成表情符号。
- **D5 Hero**：对外主句锁定为中文安全情报 + 数据评级 + AI 只建议（有 Skill 后该话术合法）。去掉「安全管家」式与代码不一致的主价值句。查询框与五区快捷入口保留。
- **C6 并入 D5**：覆盖清单单一事实源 = 核心警区配置（及既有别名表用于按钮文案）。结果页展示本次命中警区 + 覆盖范围。越界页增加「覆盖内结果长什么样」的结构示意（空槽/标注结构），禁止为越界地点计算或展示四级安全评级。
- **槽位**：槽 1 = C1a ∥ B4 ∥ N4。槽 2 = C1a 合并后 C1b ∥ D5+C6。禁止槽 1 改首页 Hero 与越界页 C6 结构（避免与尚未稳定的结果页评级依据打架；C6 结果页部分必须等 C1a）。
- **红线**：LLM 不写安全评级 / 可信度 / 越界判定 / 评级依据人话。画像不进本刀任何新的供应商请求。运行时不直连外部数据 API。不引入 LangChain / LlamaIndex / 服务型数据库。

## Testing Decisions

- 好测试只锁外部行为：契约字段内容与四档可区分、HTML 有且仅有一行评级依据、检索 top-3 含标注文档、脏输入形态枚举、首页 / 结果页 / 越界页文案与配置清单同源。不锁 CSS 像素、不锁模板字符串的每一个标点除非金标要求逐字。
- C1a：扩展结果页首屏结构测试与安全查询契约测试；⚪ / 绿 / 黄 / 红 各至少一条。断言旧硬编码倍数句消失、新字段出现。核心结论行钩子测试不得被本刀改口径。先验：D1 首屏结构锁、A3 钩子与倍数同精度。
- B4：新建检索回归（默认行为基线内即可，因零 LLM）。夹具改名单或改索引应红。对照表可以是静态文档，测试只断言文档存在且含三列数字或「hybrid ≥ BM25」类布尔，不必每次重算 embedding。先验：情报检索既有单测、金标 must_mention。
- N4：参数化打唯一接缝；先验防线 / 紧急 / 越界测试风格。禁止断言内部函数名。
- C1b：`python -m pytest tests/eval -q` 回放全绿。先验 L2 cassette 棘轮（改 `model_dump` 必须重录）。
- D5/C6：首页 / 越界 / 覆盖内结果页结构或快照；五区与配置交叉核对。紧急页回归：仍无芯片、无评级依据、无 C6 结构示意。先验 D1/D2/A4 渲染测试。
- 唯一判定：`python -m pytest tests/ -q` 全绿（基数随 C1a/B4/N4/D5 递增）。禁止裸跑 `pytest`。C1b 另跑评测目录。

## Out of Scope

- A5 画像可感知、把用户画像送进 Skill、修订隐私页「零上传」、改 ADR-0003。
- 后 100 分：Plan / ReAct / 精准查询三模式、对话条、把结果页改成聊天抄本。
- 第 4 波：引用高亮打开原文、失败分类学、知识库按场景加厚、a11y、动效。
- C4 阈值敏感性扫表 / 公式展开成表（C1 明确不做公式展开）。
- C2 细时段桶、C3 罪名中文映射、C5 地址歧义点选。
- B3 对抗金标专表、B5 Judge 人工校准、B6 换生产模型套件、B7 prompt 回归门满做。
- E2 契约版本 changelog 专票、E3 性能信封、E4 熔断演示态（除非 D5 文案必须提一句 AI 降级，不新做熔断行为）。
- N5 `?debug=1`、N6 版本钉专页、重做 N1/N3/N2/A4。
- 扩核心警区、路径级安全、LLM 参与评级、服务型数据库、换前端栈。

## Further Notes

- Craft：C1 ← S2/S5；B4 ← 检索评测习惯；N4 ← T2 脏输入；D5 ← S7；C6 ← 覆盖诚实（Redfin/S6 不做热力，只做范围边界）。
- 面试口述：灯的人话是填空不是散文；检索有独立回归；脏输入有形态；首页先承认只覆盖五区。
- 切票建议（一票一份上下文）：C1a、B4、N4、C1b、D5+C6。C1b blocked by C1a。D5+C6 blocked by C1a（结果页）。B4/N4 与 C1a 无合并前置。
- 本 spec 不替代各票派票模板；开票须含完成承诺布尔句与禁止项。
- 接缝若与实现时不一致：以唯一接缝 `execute_query` + 既有 `search` + 既有三页渲染为准，禁止为第二刀再造产品接缝。
