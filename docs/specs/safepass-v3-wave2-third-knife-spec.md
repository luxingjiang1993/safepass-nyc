## Problem Statement

第二刀已经让覆盖内结果页有确定性「评级依据」、检索有独立回归、脏输入有形态、首页承认只覆盖五区。审阅者打开仓库仍缺几块 90→95 的证据：对抗金标专表不够密、Judge 没有人工校准记录、性能信封没有可复跑的表、README 没有 Kill list 与版本钉一页。用户侧，细时段还停在昼夜两档，问「晚上 10 点」时建议与 unknowns 对不齐；Top 罪名仍可能是英文法律名；画像能改建议这件事测得到、结果页看不见；空态/熔断/缺索引的产品文案不齐。视觉仍偏后台表单，也没有浅/深主题。工程师现场改问题对着页面讲时，没有 `?debug=1`。

这些都是第 2 波清单上的剩余项。把画像送进模型、把结果页改成聊天、给用户一条「本次查询用了什么」透明条，都不是本刀的用户问题。

## Solution

十八张票、七个槽，共一个出口：波 2 剩余收口（看板本刀相关：#4 对抗专表、#8 熔断明示、#9 README+Kill list、#10 性能信封、#11 Judge 校准；C2/C3/D3/D4/A5/N5/N6/E2/E4/F1/F2/G2/B7 壳一并完成）。

- **槽 1（可并行）**：**C2** 四时段桶（灯不变）∥ **B3** 五类对抗金标每类新建 ≥10 条 ∥ **N6** 版本钉一页 ∥ **E2** 契约版本说明。
- **槽 2（C2 合并后，管线串行）**：**C3** 罪名中文 → **A5** 本机加权可感知 + 折叠只比建议 → **E4** 熔断后调用次数不增且 notice 可见。**F1** 免责与契约字段同源（可与槽 2 并行，配置键不与 C2 抢同一段则不阻塞产品语义）。
- **槽 3**：**D4** 独占前端：新网格、系统偏好 + cookie 浅/深色、紧急页独立高对比、10 槽自制 SVG。首屏五槽顺序不改。
- **槽 4（D4 之后串行渲染）**：**D3** 空态/加载/部分失败 → **N5** 仅 `?debug=1` 工程师块（不进安全查询结果的序列化、不做 D6）。
- **槽 5**：**E3** 性能信封 ∥ **F2** Guardrail 矩阵（链 B3/N1）∥ **B7 壳** ∥ **G2** 建议路径对照页；**G1** 等数字与矩阵齐后写 README 顶栏。
- **槽 6**：**L2 重录**（C2/C3/A5 之后）。不改 judge 提示词。不进默认行为基线。需密钥。
- **槽 7**：**B5** 人工 0/1 校准记录。不改 judge。对人，不是纯 agent 可收口。

后 100 分精准查询 / Plan / ReAct 不实现。画像不进任何模型请求，不改 ADR-0003，隐私页「零上传」口径不改为「画像上传」；主题 cookie 须在隐私页如实多写一句（不是画像）。

## User Stories

1. As a 覆盖内用户，I want 问「晚上 10 点」时建议和数据不足说明对齐深夜桶，so that 我不是只看到笼统昼夜。
2. As a 覆盖内用户，I want 不问钟点时仍看到原来的昼夜合计，so that 旧查询不无故变样。
3. As a 覆盖内用户，I want 某时段桶样本不够时系统诚实说未知，so that 我不会把空桶当成安全。
4. As a 覆盖内用户，I want 安全评级仍按全年相对全市均值，so that 灯不会因为我问了晚上 10 点而改档（ADR-0001）。
5. As a 开发者，I want 四桶边界只活在配置里，so that 阈值字面量不进 Python。
6. As a 开发者，I want 时段桶进入建议的数据定调而不进入用户画像，so that 钟点是查询槽位不是隐私。
7. As a 面试官，I want 偏见 / 武器 / 恐慌 / 越界编造 / 套话每类至少 10 条新金标，so that 对抗表不是 N1 骨架的别名。
8. As a 开发者，I want B3 夹具与 N1 注入攻击集分表，so that 两套报表能链接、不合成一锅。
9. As a 开发者，I want 故意放松对应防线时有金标变红，so that 拦截率不是永远 100% 的虚荣数字。
10. As a 审阅者，I want 一页写清 Python 依赖锁、pickle protocol=5、embedding 标识、FAISS ASCII 路径、cassette 指针，so that 换机器不漂有说明书。
11. As a 开发者，I want 安全查询结果增字段时有简短版本说明，so that 前端知道兼容策略。
12. As a 中文用户，I want Top5 与建议使用同一套中文罪名，so that 我不必读英文法律名。
13. As a 开发者，I want 未知罪名显式落成「其他」且不吞掉计数，so that 映射表缺口看得见。
14. As a 填了晚归女生画像的用户，I want 建议明显提到夜间或独处相关，so that 画像不是摆设。
15. As a 同一地点的用户，I want 换画像后安全评级不变，so that 我相信灯仍是数据（ADR-0002）。
16. As a 已填画像的用户，I want 默认折叠的「对比：无画像时的建议」，so that 我能看见差异而不占用 5 秒决策首屏。
17. As a 用户，I want 对比折叠里没有第二盏灯，so that 并排两灯不会暗示画像改了评级。
18. As a 未填画像的用户，I want 看不到该折叠，so that 空画像不制造假对比。
19. As a 紧急 / 越界 / 防线用户，I want 那些页没有画像对比折叠，so that 极简路径不被打断。
20. As a 隐私视角的用户，I want 二次对比请求仍不把六维送进模型，so that 零上传不被 UI 偷渡。
21. As a 用户，I want 熔断后仍看到评级和数据、建议变成模板且首屏有说明，so that 我知道这次不是 AI 建议。
22. As a 开发者，I want 熔断后 LLM 调用次数不再增加，so that 熔断是真闸不是文案。
23. As a 用户，I want 免责里的时间范围和数据来源与当次结果一致，so that 口径不漂移。
24. As a 用户，I want 无结果、加载中、提取失败、索引缺失、熔断降级各有明确态，so that 我不会对着空白页猜。
25. As a 用户，I want 降级说明出现在首屏，so that 模板建议不会装成分析。
26. As a 用户，I want 结果页不像后台表单：字号阶梯、间距、结论字重像一份冷静简报，so that 5 秒仍能决策且观感是作品集级。
27. As a 用户，I want 浅色 / 深色可跟系统，也可以页内切换并记住，so that 我不用每次重选。
28. As a 紧急用户，I want 紧急页不跟深色走、911 保持高对比，so that 电话按钮不会淹没。
29. As a 用户，I want 首页、覆盖内、越界、紧急、空态、熔断、防线、对比、法律/隐私、无法解析各有功能 SVG，so that 多状态不像临时页。
30. As a 用户，I want 插画不按灯色配犯罪场景图，so that 产品不像恐慌营销。
31. As a 覆盖内用户，I want 首屏仍是安全评级 → 核心结论行 → 评级依据 → 建议 → 追问芯片，so that D1 决策契约不被装修推翻。
32. As a 工程师审阅者，I want 加 `?debug=1` 才看见路由、检索文档标识、熔断、重试、时段桶名，so that 现场能对着页讲。
33. As a 普通用户，I want 不加 debug 时页面没有那些工程师字段，so that 本刀不做第 3 波透明条。
34. As a 紧急用户，I want debug 下最多只显示形态名，so that 紧急页仍极简。
35. As a 开发者，I want 调试信息不进入安全查询结果的序列化，so that L2 考官吃不到工程师字段。
36. As a 审阅者，I want README 顶栏有架构一图、指标、Kill list、本地三命令，so that 十分钟能懂「LLM 不评级」。
37. As a 审阅者，I want 一页写清曾用模板建议、现用 Skill+检索、评级不变式，so that 成长路径可核对。
38. As a 审阅者，I want 一张输入类型到紧急 / 防线 / 降级 / 安全的矩阵并链到测试 ID，so that 安全设计可 review。
39. As a 开发者，I want 改建议提示词时有文档强制的 L2 子集命令（壳），so that 第 3 波满做有挂钩。
40. As a 开发者，I want 查询 / 紧急 / 无 LLM / 有 Skill 的延迟数字可复跑、超阈即红，so that 性能信封不是散文。
41. As a 开发者，I want C2/C3/A5 之后重录 L2 回放全绿且不改 judge 提示词，so that 指纹跟上生成物、考官口径不动。
42. As a 项目作者，I want 抽 15–20 条人工标 0/1 并记下与 judge 的一致率和分歧，so that 「Qwen 考 Qwen」有答卷。
43. As a 项目作者，I want 校准难看也不在本刀改 judge 提示词，so that 校准票不会变成提示词重构。
44. As a 隐私视角的用户，I want 主题 cookie 在隐私页被写明，且仍不是画像、不含查询内容，so that 对外承诺与两颗 cookie 一致。
45. As a 项目作者，I want 本刀不做 Plan/ReAct/对话助手/D6/C5/A8，so that 波 3–4 与后 100 分不被偷渡。
46. As a 项目作者，I want 不重做 N1 骨架、N3、N2、A4、C1、B4、N4、D5、C6，so that 已关票不被再实现一遍。

## Implementation Decisions

- **测试接缝（优先已有，本刀不新造产品入口）**
  1. 产品唯一接缝仍是 `execute_query`：C2 时段桶的计数 / unknowns / 建议定调、C3 中文罪名、A5 建议差异与评级不变、E4 熔断后的契约形态、F1 的 `sources`/`time_range`、B3 对抗输入，全部打这一接缝。
  2. 展示接缝仍是既有页面渲染（首页 / 覆盖内 / 对比 / 越界 / 紧急 / 防线 / 降级 / 隐私）：D3 状态态、D4 主题与插画、A5 折叠、E4 notice、N5 仅查询参数 `debug=1`、F1 免责文案。不新开业务路由。主题切换可增加「写 cookie 再回到本页」的既有 HTTP 入口，不算第二产品接缝。
  3. L2 接缝仍是既有评测运行器（完整安全查询结果序列化进 judge 请求）。本刀可重录 cassette，**禁止改 judge 提示词**。N5 调试对象不得出现在该序列化里。
  4. E3 接缝：既有性能标记测试，投影到 README；阈值只进配置。
  5. B5 接缝：仓库内人工 0/1 表 + 与 L2 工件对账的一致性计算；不调用新的评测框架。
- **C2**：配置四桶清晨 / 日间 / 晚间 / 深夜。查询文本可解析出钟点则聚合该桶；不能解析则昼夜合计。该桶样本低于配置门槛 → unknowns，不编造。安全评级输入仍是全年 per-100k 相对全市，零按时段重算。时段摘要可以进入建议的数据定调（与画像无关）。图表契约若增加桶计数，属于允许触发 L2 重录的产品字段。
- **C3**：罪名映射只进配置。Top5 与建议共用。未映射 → 外显「其他」，计数保留。不引入翻译 API。
- **A5**：只强化 / 证明本机加权与时间提示；Suggestion Skill 输入打包仍不得含六维画像。同一覆盖内查询、两份画像：`rating` 相等、`suggestions` 不全等。结果页折叠「对比：无画像时的建议」仅建议列表；第二次 `execute_query` 使用空画像，仍零上传。无画像会话、紧急 / 越界 / 防线不渲染该折叠。
- **B3**：五类（偏见、武器、恐慌、越界编造、套话）每类 **新建** ≥10 条，独立夹具，ID 命名空间与 N1、主金标零交集。可复用既有守卫词表，但用例本身必须是新的。负向验证：放松对应防线 → 该类至少一条红。
- **B5**：15–20 条来自 L2 覆盖子集；人工 0/1；一致率与分歧列表进仓库。低于任何内部阈值也 **不改** judge 提示词。对人勾选，agent 不得用模型代标。
- **D3**：无结果、加载、提取失败、索引缺失、熔断降级各有可见态；降级必带 `degradation_notice` 且覆盖内首屏可见。加载态允许「提交后至响应前」的最小 HTML，不引入前端框架。
- **D4**：新 CSS 网格与字号阶梯；`prefers-color-scheme` + 页内浅/深开关写入独立 cookie（不是会话画像、不含查询）。紧急页独立高对比 class，忽略深色。10 个插画槽：首页、覆盖内页眉、越界、紧急、空态、熔断降级、防线拒绝、对比、隐私/法律共用、无法解析；自制单色 SVG，随主题变色；无位图；无按灯配图。隐私页须写明主题 cookie。D1 五槽顺序与默认折叠层级不改。
- **E2**：短 changelog / 契约版本注释：列出本刀可能新增或语义稳定的字段（时段桶、中文罪名展示、既有 `rating_rationale` 等）。不做新的服务型 API 版本号系统。
- **E3**：表含查询 P95、紧急 P95、无 LLM、有 Skill、索引内存粗值。数字可复跑；超阈红。
- **E4**：熔断后评级/数据仍在，建议来源为模板，notice 首屏可见，调用次数断言不再增加。
- **F1**：免责时间范围与来源的单一事实源 = 配置；与当次契约字段漂移测试。
- **F2**：矩阵覆盖紧急 / 防线 / 降级 / 安全（及 B3 五类），链到测试或金标 ID，并链接 N1 报表页。
- **G1**：README 顶栏：架构一图 + 既有指标表 + 短 Kill list（路径级安全、全市覆盖、登录画像、LLM 评级、服务型数据库、聊天助手等）+ 本地三命令（已有则只补缺）。
- **G2**：一页对照：配置模板建议 → Skill+检索；写明评级不变式。
- **N5**：仅 `debug=1`。字段：路由意图、检索文档标识、是否熔断、Skill 重试次数、时段桶名。无画像六维、无密钥。紧急页仅形态名或隐藏。渲染层组装，不进入 `SafetyQueryResult` 序列化。
- **N6**：`docs/reproducibility.md`（或 README 等价一节，本刀选定独立页并让 README 链过去）：依赖锁定方式、pickle protocol=5、embedding 标识、FAISS ASCII、cassette/judge 版本指针。
- **B7 壳**：文档 + eval 标记命令「改提示词须跑 L2 子集」。本刀不做「故意改坏 prompt 必红」满门闩。
- **L2 重录**：槽 6。禁止改 N2 三列 cassette。禁止把 L2 拉进默认收集。默认不改 judge 口径。
- **槽位（文件冲突，不是第二套产品依赖）**：槽 1 = C2 ∥ B3 ∥ N6 ∥ E2。槽 2 = C2 之后 C3 → A5 → E4（管线串行），F1 不与 C2 抢同一配置段则可并行。槽 3 = D4（A5 与 E4 的可见 UI 落地后再独占前端视觉）。槽 4 = D3 → N5。槽 5 = E3 ∥ F2 ∥ B7 壳 ∥ G2，G1 最后。槽 6 = L2。槽 7 = B5。
- **红线**：LLM 不写安全评级 / 可信度 / 越界判定 / 评级依据 / 时段是否够样本。画像不进供应商请求。运行时不直连外部数据 API。不引入 LangChain / LlamaIndex / 服务型数据库。不换前端栈。文案与 SVG 禁止 emoji。

## Testing Decisions

- 好测试只锁外部行为：接缝返回形态与字段、HTML 是否出现某槽/某文案、金标拦截、文档存在且含约定小节。不锁 CSS 像素、不锁 SVG path 数据、不锁 cookie 的内部编码格式（可锁 cookie 名与「无 debug 则无 doc_id」）。
- C2：有钟点 vs 无钟点输出可测差异；低样本 unknowns；两钟点若落不同桶则建议或 unknowns 可分；`rating` 不随钟点变。先验：昼夜 `is_night`、A3 钩子。
- C3：fixture 出现过的类型有中文；未知 →「其他」；图表标题与建议同词。先验：charts 结构测试。
- A5：同区两 profile，`rating` 相等、`suggestions` 不全等；HTML 折叠默认闭合、无第二盏灯；空画像无该块。先验：画像不变评级集。
- B3：每类计数 ≥10；与 N1 ID 零交集；放松防线负向红。先验：N1 注入金标与报表对账。
- B5：表有 15–20 行人工列；一致率可算；无「改了 judge prompt」的 diff。对人勾选后测试只对账，不代标。
- D3：每态至少一条渲染或接缝测试。先验：既有降级横幅、紧急页。
- D4：`prefers-color-scheme` 与显式 cookie 的 html class 可分；紧急页 class 不含深色主题；10 槽各有一处插画标记；D1 槽序结构锁仍绿。先验：D1 首屏结构。
- N5：无 debug 的覆盖内 HTML 不含检索文档标识与 retry；有 debug 含约定字段。先验：D1/A4 渲染。
- E3：`pytest -m perf`（或等价）可红；README 数字与测试口径同源或注明投影。
- E4：熔断后调用计数冻结 + notice 可见。先验：预算熔断包装器测试。
- F1：改配置时间范围 → 免责与契约同时变，否则红。
- L2：`python -m pytest tests/eval -q` 回放全绿。N2 对照套件不因本票误伤。
