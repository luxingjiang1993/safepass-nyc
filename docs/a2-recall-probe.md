# A2 召回探针：检索能否承载金标 must_mention 事实（issue 17 先测后建证据）

- **日期**：2026-09-08
- **前置**：A1（issue 16）已合并；本票开工第一动作（P6 定案 1）
- **结论**：**探针通过（20/20）**。知识库 + 混合检索能在 top-3 召回 must_mention
  类事实的承载文档，A2 可以开工，C8 知识库加厚不阻塞本票（可作为后续
  滚动日程的候选，见文末）。

## 方法

对「金标 L2 must_mention 将断言的事实」逐条构造探针查询，跑
`safepass.intel_agent.search()`（FAISS 向量 + BM25 关键词，RRF 融合 top-3），
检查承载该事实的知识文档是否出现在 top-3。

探针分两波：

- **波 1（12 条）**：主题词 + 地名查询——事实的「可检索性」下界（BM25 专名
  信号最容易命中的形态）。
- **波 2（8 条）**：自然语言整句查询——真实用户问法，不带事实关键词填充，
  是产品形态的诚实检验。

事实 → 承载文档的映射来自 `fixtures/knowledge/` 15 篇文档的逐节盘点：
scam 篇承载诈骗提醒（冒充使领馆/换汇/亲情/租房等），overview 篇承载仇恨
犯罪记载与夜间注意事项，emergency 篇承载中文警员/法律援助/911 中文翻译。

## 对 DoD 的含义

1. **同警区不同 query 的检索差异**：波 2 中「法拉盛 诈骗」→ 首条 p109_scam、
   「法拉盛 报案中文」→ 首条 p109_emergency——同一警区不同 query 的 top-3
   构成可测差异，这是「建议/grounds 可测差异」的检索侧前提。
2. **must_mention 命中检索事实**：两波 20 条事实全部在 top-3 内命中承载
   文档，A2 注入 top-3 后金标可以咬合「建议引用了检索事实」。
3. **C8 知识库加厚**：当前 15 篇文档（5 警区 × 3 主题）对本票 DoD 够用，
   不触发「测不过暂停」分支；若后续 N1 攻击金标或 B1 金标扩充出现新的
   must_mention 事实形态，再按滚动日程评估加厚。
